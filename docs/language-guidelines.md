# 🗣️ Guía de Lenguaje – GoVenue (Argentina/Latam)

Este documento define el uso del idioma y el estilo de texto para el MVP de GoVenue. Su objetivo es mantener consistencia en toda la interfaz del producto y documentación.

---

## 🌎 Idioma oficial del MVP

- **Español Argentina/Latam**
- Sin formalismos excesivos.
- Lenguaje claro, práctico y deportivo.

Ejemplo:  
✔ “Crear evento”  
✔ “Buscar sedes”  
✔ “Mis eventos”

---

## 🧍 Terminología del usuario

| Término | Uso |
|---------|-----|
| **Participante** | Persona que busca o asiste a eventos |
| **Organizador** | Persona que crea eventos |
| **Administrador de sede (Venue)** | Responsable de un espacio físico |
| **Admin del sistema** | Gestión interna de GoVenue |

> ❗ Nunca usar “Cliente” o “Consumidor” en la UI del MVP.

---

## 🏟️ Terminología del venue y los eventos

| Concepto | Término a usar |
|----------|----------------|
| Lugar físico | **Sede deportiva** |
| Actividad | **Evento deportivo** |
| Lugar dentro de la sede | **Cancha / Espacio** (cuando aplique) |
| Pública disponible | **Publicado** |
| No visible | **Borrador** |
| Superado el cupo | **Completo** |
| No se realizará | **Cancelado** |

---

## 💬 Tono y estilo

| Característica | Descripción |
|----------------|-------------|
| Claro | Sin textos técnicos innecesarios |
| Cercano | Tratamiento directo, humano |
| Deportivo | Dinámico, ágil, sin exageración |
| Neutral regional | Evitar modismos extremos, pero usar naturalidad Latam |

### Ejemplos
✔ “Elegí una sede para tu evento.”  
✔ “Buscá eventos por deporte, zona y fecha.”  
❌ “Seleccione el establecimiento para efectuar su actividad.”

---

## 🔤 Formato y escritura

- **Capitalización:** usar mayúsculas solo en nombres propios, títulos y botones.
  - ✔ “Crear evento” (botón)
  - ❌ “CREAR EVENTO”
- **Fechas:** formato evento → `15/08/2026 – 19:00 hs`
- **Monedas:** formato futuro → `$ precio` (solo en fases posteriores)

---

## 📌 Palabras a evitar en el MVP

| Palabra NO | Motivo |
|------------|--------|
| Consumidor | Suena a compra/venta (no es MVP) |
| Cliente | No hay modelo comercial en MVP |
| Ticket | Podría confundirse con entradas de espectáculos |
| Reservas | Solo después de fase 3 |
| Turno | Según deporte puede causar confusión |
